Para utilizar este programa e necessário ter instalado o visual studio com desenvolvimento para desktop com .net e SQL Server Manegement Studio.
Quando o programa e iniciado é nos mostrado o form login , pela primeira vez apenas existe um utilizador criado (utilizador: Gestor | password: 1234), após realizar o login é nos apresentados o formKanban que é o nosso formulário que nos dá acesso a todos os outros forms consoante o nosso tipo de utilizador

Programador :

- Pode ver todas as Tarefas atribuídas pelo seu Gestor mas apenas pode realizar as que lhe foram atribuidas

- Pode Alterar os estados das tarefas

- Acesso aos detalhes de todas as tarefas a serem desenvolvidas e todas as que já foram concluidas


Gestor :

- Pode criar Utilizadores

- Pode gerir os Utilizadores ao selecionar um e clicar no botão de criar utilizadores

- Pode criar Tarefas

- Pode gerir as Tarefas ao selecionar uma e clicar no botão de criar tarefas

- Pode criar TipoTarefas no form que é acessível através da respetiva opção na listagem

- Pode gerir as TipoTarefas ao selecionar uma e clicar no botão de criar tarefas

- Acesso aos detalhes de todas as tarefas a serem desenvolvidas e todas as que já foram concluidas


No Form frmGereUtilizadores é nos apresentados todos os Utilizadores que estão criados na nossa Base de Dados.
